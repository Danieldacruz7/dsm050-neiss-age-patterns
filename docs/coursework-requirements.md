### Page 2: Introduction

Following the initial exploration and practical application of Python for data preparation,
manipulation, visualisation selection and evaluation, this phase challenges you to explore
deeper insights in a dataset. You will be expected to demonstrate both technical fluency and
critical thinking as you further develop your ability to draw more refined conclusions and
produce compelling visual narratives supported by robust data handling.

### Final coursework assignment: Project: Assignment specification

Design and implement data visualisations that **reveal significant insight in a given dataset
of choice** using suitable Python libraries and techniques. The purpose of this assessment is
to demonstrate your ability to **design, justify and critically evaluate a complete data
visualisation workflow**. Hence, produce a report as a **PDF file (3000–3500 words)** of a data
visualisation-led investigation **different from coursework assignment 1**.

You are required to:

- select a relevant topic and identify **one publicly and accessible dataset** that is
  appropriate with the selected domain, and apply data wrangling and visualization and draw
  deeper insights;
- formulate **five research questions** that are relevant to the topic and dataset;
- prepare and transform the dataset appropriately, addressing any structural formatting to
  ensure coherent analysis;
- critically reflect on the process, discuss the limitations, assumptions, and the added value
  gained in the project.

> **IMPORTANT: beware of data found on Kaggle and other sources where the datasets are heavily
> processed and code for visualisation is present with multiple python codes/analysis. This
> will reduce your score.**

**Note on GenAI:** GenAI can be used for research with appropriate references, code debugging,
data-visualisation prototypes with proper declaration. Example:

> "I acknowledge the use of [1] ChatGPT (https://chat.openai.com/) to [2] generate materials for
> background research and self-study in the drafting of this assessment. I entered the following
> prompts on 4 January 2026: [3] Write a 50 word summary about the history of Goldsmiths,
> University of London. Write it in an academic style. Add references and quotations from
> scholarly articles."

All AI contributions must be critically evaluated and cited. **AI must not be used to generate
full analytical reports, write entire sections of the final report, or fabricate data.**

### Submission requirements

**1. Final Report (PDF)**
Submit your report as a **PDF file and Github repository link** (approx. **3,000–3,500 words**).
The final report must be submitted in PDF format and prepared using a document editor. All
visualisations, figures, and images generated as part of the analysis must be properly saved,
clearly labelled, and **embedded within the report**. These should be used to illustrate key
findings and support your discussion. In addition, the report must include **a link to a copy of
the dataset** used in your analysis.

**2. Jupyter Notebook (.ipynb)**
You must submit **a copy of the data used in your analysis** and the **notebook (.ipynb)** in a
**Github repository**.

### Report guidelines (mark allocation)

Reports should include discussion of the following points.

**1. Research topic and background: [15%]**
- Introduction / overview of topic
- Overview of key findings
- Research objectives and motivation
- Identify and define important concepts w.r.t. research question(s) (reference
  academic/technical literature where appropriate)

**2. Data sources: [5%]**
- Where/how did you find them?
- How/why was the data initially collected?
- Are there any ethical or legal issues?
- Critically evaluate your data: is the data trustworthy, and valid for your purposes?

**3. Data overview and pre-processing: [10%]**
- Brief description of key variables
- Handling of missing or erroneous data
- Data summary statistics
- Number of observations in the data
- Summary of demographics and key variables
- Use of tables or easily understandable quantities in prose

**4. Analysis: [50%]**
- Visualise key variables
- Visualise relationships between variables
- Aim for high quality explanatory visualisation that describes or tells a story about the
  behaviour or phenomena under investigation
- **Full marks will require an example of a more specialised or advanced type of visualisation**,
  e.g. time-series, geospatial, clustering, qualitative data, etc. Essentially, from **topic 6–10**
- Methodical data visualisation process

**5. Conclusion and evaluation: [10%]**
- Summarise key findings
- Evaluate your process and visualisations
- Challenges / limitations
- Things to improve and/or pointers to future research

**6. Critical Engagement with AI: [10%]**
- Evidence of independent thinking beyond AI output
- Correct identification of AI limitations
- Appropriate citation / acknowledgement

> Make sure **all code runs correctly prior to submission**.

(Total: 15 + 5 + 10 + 50 + 10 + 10 = 100%)

<https://learn.london.ac.uk/mod/resource/view.php?id=238610>

**`Data Visualisation Coursework Template.ipynb`** (11 cells).

Notebook structure (all markdown headings, to be filled in):

1. `# Data Visualisation Coursework Template` (intro cell: instructions, delete before submitting)
2. `## Introduction`
3. `## Research topic`
4. `## Data collection / Survey design`
5. `## Data overview and pre-processing`
6. `## Analysis and results`
7. `## Conclusions`
8. `## References`
9. `## Appendices`
10. `## Word Count` (explanatory markdown)
11. code cell: `%%js` word-count script

Instructions embedded in the template:

- "These headings are only a recommended structure."
- "The wordcount code only works in **Jupyter Notebook**! You can still use JupyterLab to produce
  your report if you wish but you will need to use Jupyter Notebook to check the number of words."
- The word-count code counts words in **Markdown cells only**; code cells are not included.
- `Main word count` = words in the main body **excluding** references or appendices; only this
  figure relates to the assignment word limit. There is no limit on words in references or
  appendices. "Appendices should only be used to provide context or supporting information.
  **No marks will be directly awarded for material submitted in appendices.**"
- "Please do not modify the word count code!"
- To exclude references from the word count **you must** have a cell starting with `## References` :
  everything below it is excluded.
- If submitting appendices **you must** have a cell starting with `## Appendices`: everything below
  it is excluded. If you have no appendices you can delete that cell.
- "Code comments should only be used to explain details of the implementation, not for discussing
  your findings. All analysis commentary **must** be written in Markdown cells. **No marks will be
  awarded for analysis discussion submitted as comments in code cells.**"
